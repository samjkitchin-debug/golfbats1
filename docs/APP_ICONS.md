# App Icons

This document tracks app icon assets and their locations.

## App Icon

The app icon is a vibrant, stylized golf course illustration showing:
- A golf course landscape with rolling green hills
- A bright orange sun with yellow/orange rays
- A putting green with an orange-red flag
- A blue S-shaped water feature
- Rounded rectangular frame with glowing aura

**Recommended location:** `public/app-icon.png`

**Usage:**
- App manifest icons
- PWA icons
- Mobile app icons (if needed)
- Favicon variants

## Logo

The DayForeIt logo is stored at:
- `public/logo.png`

Used for:
- Header branding
- Login page
- Navigation

## Notes

- All icons should use transparent backgrounds where possible
- Icons should work on both light and dark backgrounds
- Maintain aspect ratios to prevent distortion
